
# Hospital Management System

## Project Overview
A console-based Hospital Management System developed using Java. This application helps administrators and receptionists manage patients, doctors, appointments, and medical bills.

## Features

### 1. Login System
- Admin Login
- Receptionist Login
- Password Hashing using SHA-256
- Maximum 3 Login Attempts

### 2. Patient Management
- Register Patient
- View Patients
- Search Patient
- Update Patient
- Delete Patient
- Discharge Patient

### 3. Doctor Management
- Add Doctor
- View Doctors
- Search Doctor
- Update Doctor
- Delete Doctor

### 4. Appointment Management
- Book Appointment
- View Appointments
- Validate Patient and Doctor IDs
- Prevent Duplicate Appointments
- Prevent Booking for Discharged Patients

### 5. Medical Billing
- Calculate Medical Bill
- Add New Charges
- Display Total Bill
- Generate Final Bill During Discharge

### 6. Data Storage
- Save data in text files
- Load data when the application starts
- Preserve data after restarting the application

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Exception Handling
- Scanner
- SHA-256 Hashing
